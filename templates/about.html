PROJECT NOTES

About this study

Credit Card Fraud Detection System and Fraud Analytics Dashboard.

Objective

Compare five machine-learning classifiers for identifying potentially fraudulent transactions and assess how class imbalance affects their performance.

Dataset

The Kaggle European cardholder dataset contains Time, 28 anonymized PCA features (V1–V28), Amount, and Class. Class 0 is genuine and Class 1 is fraud. The PCA features are not merchant, location, or card identity fields.

Algorithms

Logistic Regression, Decision Tree, Random Forest, Bagging, and AdaBoost are each trained on original and SMOTE-resampled training data.

Class imbalance

Fraud represents a small share of transactions. Accuracy can be misleading; precision, recall, F1, PR-AUC, and confusion matrices are useful measures. SMOTE is applied only within the training pipeline.

Evaluation

Models are trained on a stratified 80% training split and evaluated on the same untouched 20% test split. ROC and precision-recall curves are generated from test-set predictions.

Technology

Python, pandas, NumPy, scikit-learn, imbalanced-learn, Matplotlib, Flask, Jinja2, Bootstrap 5, Chart.js, and Joblib.
