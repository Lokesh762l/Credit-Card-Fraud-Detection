PROJECT NOTES

About this study

Credit Card Fraud Detection System with SHAP Explainability and Fraud Analytics Dashboard.

Objective

Compare five machine learning classifiers for identifying potentially fraudulent transactions, assess class imbalance, and explain model predictions.

Dataset

The Kaggle European cardholder dataset contains Time, 28 anonymized PCA features (V1–V28), Amount, and Class. Class 0 is genuine and Class 1 is fraud. The PCA features are not merchant, location, or card identity fields.

Algorithms

Logistic Regression, Decision Tree, Random Forest, Bagging Classifier, and AdaBoost are each trained on original and SMOTE-resampled training data.

Class imbalance

Fraud represents a small share of transactions. Accuracy can be misleading; precision, recall, F1, and PR-AUC are important measures. SMOTE is applied only within the training pipeline.

SHAP

Permutation SHAP explains model output as contributions in fraud probability space (Class 1). It describes model behavior and does not identify the actual cause of fraud.

Technology

Python, pandas, NumPy, scikit-learn, imbalanced-learn, SHAP, Matplotlib, Flask, Jinja2, Bootstrap 5, Chart.js, and Joblib.
